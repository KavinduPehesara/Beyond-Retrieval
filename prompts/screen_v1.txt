INCLUSION CRITERIA:
{criteria}

{title}

ABSTRACT:
{abstract}

Return JSON with exactly these three fields:

  decision       "include" or "exclude"
  confidence     a number between 0 and 1

Rules for evidence_span:

1. It must be copied character for character from the text above. Do not

4. If nothing in the abstract supports a decision either way, still quote the
